GPT-6.1 Terra and the new economics of computer-use agents: what to change, and what to test first

OpenAI's new mid-tier model is pitched at computer use and coding at half the price of the models above it. Cheaper capable models change agent architecture more than frontier launches do, but only for teams that can measure quality and cost per task.

AnalysisSumanta Mukhopadhyay29 Oct 2026 · 08:20 GST7 min read6 sources
#news#ai#llm#agents
Book a 30-min call → Analyse your challenge

What was released

OpenAI released GPT-6.1 Terra on 26 October 2026, a mid-sized model aimed at computer use, visual reasoning and coding, available in ChatGPT and Codex2. Quartz reports API pricing of $1 per million input tokens and $5 per million output tokens, half the price of the models it sits below, along with benchmark gains that come from OpenAI's own testing1. Coverage of the cost per task compared with competing frontier models varies between outlets, from about nine to about twelve times lower34, which is a reminder that these are vendor-sourced comparisons, not independent results.

Why mid-tier releases matter more than frontier ones

Agents that operate software make many model calls per task: read the screen, decide, act, check, repeat. Most of those steps are routine. A capable, cheaper model in the middle tier changes the cost of the whole loop, while frontier models are only needed for the hard decisions. The architecture that benefits is one that already routes by step difficulty and measures cost per completed task.

More on the pattern in LLM model routing.

How to decide whether to switch

The measurement layer is where most teams fall short. OpenTelemetry's GenAI conventions record each model call with the requested model, token usage split into input and output, and latency, so you can compare models side by side and estimate cost per request5.

Price per token is a vendor's number. Cost per completed task is yours. Only the second one should drive a model switch.

Sandboxing matters even more when agents get cheaper and run more often; see what Anthropic's S-1 teaches about sandboxing agents.

CTO take

Treat this release as a prompt to build the plumbing, not as a reason to switch. If you can already measure quality and cost per task by step type, a cheaper capable model is close to free money: route the routine steps and keep the hard ones where they are. If you cannot, the first job is the evaluation set and the telemetry. That is true whether your teams are in the US, Europe, India or Asia-Pacific; data-location rules differ by market, so check them before sending screens and documents to any new model (by region).

FAQ

Common questions

What is GPT-6.1 Terra?

A mid-sized OpenAI model released on 26 October 2026 for computer use, visual reasoning and coding, available in ChatGPT and Codex. Reported API pricing is $1 per million input tokens and $5 per million output tokens.

Should we switch our agents to a cheaper model?

Only after running your own evaluation set. Vendor benchmarks do not reflect your tasks, and reports of cost per task differ. Route the steps where the cheaper model matches quality, and keep stronger models for the rest.

How do we measure cost per task for an agent?

Instrument every model call with OpenTelemetry GenAI conventions, recording model, input and output tokens and duration, and group calls by task or trace. Cost per completed task, not per token, is the number that matters.
